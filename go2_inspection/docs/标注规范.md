# GO2 最新赛项视觉样本与标注规范

本规范与《最新赛项对齐矩阵》配套。现场样本未到位前，不新增无法验证的识别类别或
占位权重。每张新增样本必须保留原图、拍摄时间、类别或读数真值和现场位置。

## 1. 数据单位

- 一次 `capture_id` 对应同一拍摄序列的一至多张连续照片；同一序列不得拆入不同数据集。
- 每批采集必须保存 `metadata.json`，至少包含 `capture_id`、`batch_id`、`station_id`、`camera_id`、`capture_time`、`robot_pose`。
- 原图不得覆盖或二次压缩；旋转、裁剪和增强只在训练阶段产生。

## 2. 标签文件

每张图片使用 `<原文件名>.labels.json`，例如：

```text
frame_01.jpg
frame_01.jpg.labels.json
```

标注文件是数组，矩形框统一采用原图像素坐标 `xyxy`：

```json
[
  {
    "class": "station_marker",
    "bbox_xyxy": [510, 330, 750, 610],
    "attributes": {
      "occluded": false,
      "difficult": false
    }
  }
]
```

确认没有任何目标的负样本必须保存空数组 `[]`；缺少标签文件表示“尚未标注”，转换脚本不会把它当成负样本。

## 3. 画框规则

- 框紧贴目标可见边缘，不额外包含大片背景。
- 被遮挡但仍可确定类别时，框目标可推断的完整外接矩形，并设置 `occluded=true`。
- 同一目标只画一个框；静止传送带场景不增加跟踪 ID。
- 煤堆只标注“存在区域”的外接框，不标体积、重量或精细轮廓。
- 指针表、数字表先标整个表体；后续 ROI 可单独增加显示区或表盘标注任务。
- 模糊、强反光、严重遮挡等无法用于可靠判断的样本保留，并设置 `difficult=true`。

新增样本必须分别覆盖：5 类巡检标牌；彩色布条与空皮带负样本；堆煤与积水/阴影
负样本；LED 表读数及红绿灯亮灭；3 个水泵仪表的读数真值、量程和刻度标定；损坏
托辊与完好托辊。现有 1～10 编号牌只用于托辊位置关联，不属于 5 类巡检标牌。

## 4. 类别冻结

模型标签必须来自 `configs/classes.json` 的键。新增、合并或重命名类别时先更新配置和本规范，不允许在同一次训练数据中混用旧名称。

当前配置只保留历史数据解释和现有算法需要的煤堆、仪表及编号牌映射，均不表示新增
赛项已经具有可训练现场数据。样本到位后再决定检测模型、颜色规则和指针标定方案。

## 5. 质检与切分

1. 运行 `scripts/prepare_dataset.py` 生成清单和质量报告。
2. 人工复核 `quality_issues.csv` 中的坏图、过暗、过曝、模糊和重复候选。
3. 标注完成后运行 `scripts/build_yolo_dataset.py`。
4. 训练、验证、测试按 `batch_id + capture_id` 分组；冻结测试集在最终统计前不得参与训练或调参。
