## 当前报告项目 ID

报告总览使用 `roller_jam`、`foreign_object`、`coal_pile`、
`inspection_marker`、`substation_led_meter`、`indicator_red`、
`indicator_green`、`pump_analog_meters`、`gas_ch4`、`gas_o2`、`gas_co`、
`gas_h2s` 和 `equipment_temperature`。`station_number` 是内部位置关联能力，不是
独立计分项目。

报告继续使用“完成检测 → 人工复核/修正 → 人工确认 → 开放 Word 报告”的流程。
历史数据库、样本、模型和原始识别 JSON 不删除；展示与报告忽略退役模块。

## 第二阶段样本要求

分别收集：5 类巡检标牌；彩色布条与空皮带负样本；堆煤与积水/阴影负样本；LED 表
及红绿灯；3 个指针表及其读数真值、量程和刻度标定；损坏托辊。每张样本必须保留
原图、拍摄时间、类别或读数真值和位置。同一拍摄序列按组切分，禁止跨训练集与测试集。
样本到位后再确定检测模型、颜色规则和指针标定方案。
